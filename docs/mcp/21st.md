# Guia de conexão — 21st.dev Magic MCP

O `mcp:21st` gera componentes de UI a partir de linguagem natural. Precisa de uma API key da 21st.dev.

## 1. Criar conta e gerar a API key

1. Acesse https://21st.dev e crie/entre na sua conta.
2. Vá em **Settings → API** (ou Magic MCP) e gere uma **API key**.
3. Copie a key (formato começa com algo como `21st_...`).

## 2. Onde colocar

A CLI **não grava a key** — você a fornece no ambiente. Opções:

- Variável de ambiente: `export TWENTYFIRST_API_KEY="sua-key"` (no seu shell rc).
- Ou no `.env` do projeto (nunca commite o `.env`).

## 3. Registrar o MCP

Feito pela `setup-definitivo init` (ou manualmente, por harness). Exemplo genérico:

```bash
# Claude Code
claude mcp add magic -- npx -y @21st-dev/magic@latest
```

> Confirme o pacote/flags exatos na documentação oficial da 21st.dev antes de publicar.

## 4. Testar

Abra seu harness e peça um componente simples (ex.: "gere um card de preço com Tailwind"). Se retornar código de componente, está conectado.

## Problemas comuns

- **401/403**: key inválida ou não exportada no shell atual — reabra o terminal.
- **command not found**: falta Node/npx no PATH.
