# Guia de conexão — 21st.dev

O `tool:21st` dá acesso à geração de componentes de UI do 21st.dev.

## Por que é `tool` e não `mcp`

O 21st **não é um servidor MCP stdio**. Ele é um MCP **HTTP**: o cliente aponta para uma
URL (`https://21st.dev/api/mcp`) e envia a API key em um header. Isso não cabe no formato
`comando + argumentos` que a CLI usa para registrar MCPs stdio.

Além disso, o 21st tem instalador próprio que faz o registro **e** o login. Rodar o
instalador oficial é mais confiável que a CLI tentar reproduzir o formato dele.

> O pacote `@21st-dev/magic`, que aparece em configurações antigas, hoje é apenas um proxy
> de compatibilidade depreciado. Novas instalações usam `@21st-dev/cli`.

## 1. Instalar e conectar

```bash
npx -y @21st-dev/cli@latest init
```

O instalador abre o navegador para você entrar na conta, gera a credencial e registra o
MCP no harness detectado. É o que a CLI executa quando você seleciona `tool:21st`.

Comandos úteis do CLI:

```bash
npx @21st-dev/cli@latest login     # entrar
npx @21st-dev/cli@latest whoami    # ver a conta conectada
npx @21st-dev/cli@latest logout    # sair
```

## 2. Onde a credencial fica

O próprio CLI grava a credencial na configuração do harness. Em alguns formatos ela vai
**em texto puro** — por exemplo, no `~/.codex/config.toml`:

```toml
[mcp_servers.21st.http_headers]
x-api-key = "..."
```

Implicações práticas:

- **Nunca versione esse arquivo** nem o inclua em backup público.
- Se o arquivo vazar, **rotacione a chave** em https://21st.dev e apague backups antigos
  (`*.bak-*`) que contenham a versão antiga.
- Confira as permissões: o arquivo deve ser `0600` (só o seu usuário lê).

A `setup-definitivo` nunca pede, lê ou grava essa credencial — quem cuida dela é o CLI do
21st.

## 3. Testar

No seu harness, peça um componente simples: *"gere um card de preço com Tailwind"*. Se
voltar código de componente, está conectado.

## Problemas comuns

- **401 / 403**: sessão expirada — rode `npx @21st-dev/cli@latest login` de novo.
- **command not found**: falta Node/npx no PATH.
- **O MCP não aparece no harness**: confirme que o `init` detectou o harness certo; alguns
  exigem reiniciar a sessão para recarregar a lista de servidores.
